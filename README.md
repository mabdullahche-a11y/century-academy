# Century Academy homepage concept

Buildless HTML/CSS/JavaScript homepage. Serve `dist` using a static HTTP server.

The trial dialog prepares and copies an enquiry without submitting a booking or collecting personal details. Connect the real WhatsApp number before launch. Teacher names, portraits, testimonials and detailed syllabus claims are intentionally omitted until approved materials are available.

Photographic assets were downloaded from Unsplash image delivery URLs: library `photo-1507842217343-583bb7270b66`, writing `photo-1455390582262-044cdead277a`, books `photo-1481627834876-b7833e8f5570`. Heading type uses Cormorant Garamond; body uses DM Sans through Google Fonts, with local system fallbacks.
